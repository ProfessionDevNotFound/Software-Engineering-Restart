# Function Game 🎮

A beginner Python project created to practice and understand different concepts related to **Python functions**.

The program provides a simple menu where the user can choose different functions to perform different tasks.

## Features

The program currently supports:

1. **Print your name**
2. **Get your complete bio details**
3. **Calculate the square of a number**
4. **Exit the program**

## Concepts Practiced

This project is mainly focused on understanding:

- Defining functions
- Calling functions
- Returning values using `return`
- Passing arguments to functions
- Using default/optional values
- Function chaining
- Conditional statements
- User input
- Type conversion
- String manipulation using `split()`
- Working with Python's `datetime` module
- Using `if __name__ == "__main__"`
